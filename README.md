# Ranking de Videojuegos
### Nombre del repositorio 🚀

#### ✅ Descripcion del proyecto:
Aplicacion de consola desarrollado en Python para obtener los 3 videojuegos mejor valorados en base a su puntuación
- Añadir juego
- Actualizar puntuación
- Juegos mejor valorados

## 👾 *Como ejecutar el proyecto*
1. Crear un directorio especifico para el proyecto
2. Clonar el repositorio en el direcotrio especificado:
```bash
git clone https://github.com/Anderson-Oloroso/RankingVideojuegos.git
```
3. Abrir el proyecto
4. Ejecutar el archivo "RankingVideojuegos.py"

## 👾 *Archivos del proyecto*
Archivo único: RankingVideojuegos.py
